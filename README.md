
# 🌱 Sprout: Little Minds • Big Adventures

Sprout is a fun and interactive Android learning app designed for young children. It combines education, creativity, and play to make learning enjoyable through colorful activities and engaging experiences.

✨ Features

* 🔤 Learn Alphabets & Numbers
* 🎨 Explore Colors & Shapes
* 🦁 Discover Animals & Stories
* 🧩 Fun Puzzles & Drawing Activities
* 📷 Camera-based Learning
* ⭐ Rewards & Achievement Badges
* 👨‍👩‍👧 Parent Dashboard for Progress Tracking

🛠️ Built With

* Kotlin
* XML
* Material Design 3
* MVVM Architecture
* Room Database
* CameraX
* Google ML Kit
* Lottie Animations

🎯 Goal

To create a safe, engaging, and child-friendly learning experience that encourages curiosity, creativity, and early education through play.
